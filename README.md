# 地球：人类 / Earth Human

`地球：人类` 是一个可独立安装的 Minecraft mod，目标是复刻真实人类在世界中的身体、环境与生活约束。

它不是 `Earth on Minecraft / 我的地球` 的强制依赖，也不会把人物生存压力塞进本体。四个项目属于同一可选生态：拆分用于并行开发和让玩家自由选装，组合安装时通过标签和共享数据自动联动。

- `Earth on Minecraft / 我的地球`：复刻真实世界常见物质、来源、产业、设施和路线。
- `地球：人类`：复刻真实人体、生存压力、环境影响、健康与生活系统。
- `Earth Online: Magic` 与 `地球 Online：玄幻`：提供可选超凡路线，并通过 `earth_online_arcana.*` 向人物系统提供适应加成。

本分支（`release/neoforge-26.1.2`）面向 MC 26.1.2 / NeoForge 26.1.2.124，`main` 分支面向 MC 26.2 / NeoForge 26.2.0.93。两者均可独立运行，也会消费 `Earth on Minecraft` 的饮水与后续环境角色接口。

详细初版方案见 [docs/initial-plan.md](docs/initial-plan.md)。

当前实现复盘、验证证据和剩余边界见 [docs/CURRENT_AUDIT_20260719.md](docs/CURRENT_AUDIT_20260719.md)。

## v0.1.20 测试版内容

- 打开原版生存背包时，身体小人继续显示在正常 HUD 的同一角落，不占用原版玩家模型区域；悬浮可查看头部、躯干、四肢完整度，点击可打开完整身体状态界面。
- `野外健康记录` 改为说明型入门手册，保留进入实时身体状态的按钮。
- 普通近战、投掷物与爆炸在核心中只走原版生命、护甲、吸收心与其他 Mod 的结算，不再附加部位受击伤；精细命中路由仅保留给可选身体血量附属。
- 25 个物品贴图已统一重绘为经过最终 32px 审查的 Image-2 现代野外健康风格；提示词和来源记录见 [docs/art-provenance.md](docs/art-provenance.md)。
- 状态页现已覆盖健康、腿伤、右手伤、严重伤、缺少护理物品、护理中与护理失败等反馈；小屏幕建议和长英文文本会换行，不再只显示省略号。

- 新增 `EarthHumanApi v1`：其他可选 Mod 可以读取人体快照，并通过服务端权威入口降低疲劳、治疗指定部位，不再需要直接修改地球：人类的私有存档数据。

- 活动检测不再每秒只读取一次瞬时速度，而是读取原版逐 tick 累积的移动统计增量；步行、疾跑、游泳/涉水、攀爬、载具、鞘翅和飞行分别结算。
- 疲劳、水分、连续活动负荷和部位训练改为按实际移动距离计算；载具只产生极低负荷，不再被误判成腿部步行训练。
- `/eh status text` 和图形概览页会显示当前活动与连续负荷；小高度窗口下概览布局会自动压缩，避免状态条、建议和按钮重叠。
- 新增标准 NeoForge common 配置 `earth_human-common.toml`：核心系统可独立开关，并提供轻松、标准、真实、自定义四种调节预设。
- 核心默认保持原版生命条和其他 Mod 的伤害、护甲、吸收心、治疗与死亡流程不变；身体完整度和伤情作为独立状态记录。
- 高处摔落会增加腿部伤情，影响移动但不影响手；空手挖掘硬石或空手接触仙人掌会增加右手伤情，影响挖掘但不影响行走。
- 部位生命拆分已移入独立的 `Earth Human: Body Health` 附属，核心不再因为安装本体而接管生命结算。
- 修复旧身体模型在额外最大生命下迁移后比例偏低的问题；其他 Mod 改变最大生命时，已有伤势比例继续保持。
- 新增伤害类型数据标签 `bypasses_body`、`head_priority`、`full_body`，供数据包和其他 Mod 无 Java 硬依赖接入。
- 新增身体容量、旧存档迁移、兼容伤害映射、治疗溢出和规则解析自动测试。
- 快捷护理现在显示服务端真实进度，可主动取消；完成前会校验原始物品 ID 与组件，失败或无需护理时不会误耗替代物品，并在界面直接说明原因。
- 新增完整身体状态面板：概览、身体、快捷护理和显示设置四页；可用 `/eh status` 或右键野外健康记录打开。
- 快捷护理是服务端权威动作：开始后等待对应时间，完成时重新检查并消耗背包物品，不接受客户端直接修改状态。
- 护理物品兼容使用公开 item tags：其他 mod 或数据包可把物品加入补水、包扎、急救、保暖、降温分类，无需硬依赖 Java 类。
- HUD 可单独开关基础状态和身体小人，可隐藏数字、切换三种配色主题，并继续调整身体小人的角落、大小和透明度。
- `/eh status text` 保留旧文字状态输出，避免习惯旧命令或自动化调用的玩家失去入口。

- 玩家持久状态：水分、体温、疲劳。
- 身体完整度采用稳定的三类模型：头部 5、躯干 7、四肢 8；旧六部位存档会把四条肢体按完整度归并到四肢，不会重置长期状态。
- 原版红心始终由 Minecraft 和其他 Mod 负责；核心不会接管最大生命、治疗、护甲或死亡流程。只有安装独立身体血量附属后，才可选择 `head_bar` 部位生命桥接模式。
- 其他 mod 提供的最大生命会按比例扩展身体完整度容量，但核心中的普通回血只恢复原版生命，不会暗中改写身体数据。
- 僵尸近战、投掷物、爆炸和常规火焰伤害不会在核心里生成部位受击伤；可选身体血量附属使用原版已经完成护甲与药水减伤后的最终伤害，避免重复减伤。
- 原版生命不再被解释成部位血条；身体数据首次接入时从原版状态初始化，之后作为长期角色状态保存，不会每次复活重新分配。
- 仅安装 `Earth Human: Body Health` 并启用部位生命桥接时，躯干和四肢归零才进入附属的失能与伤害扩散规则；核心本身不接管普通战斗扣血。
- 起跳会给四肢极轻微的使用损耗；受伤四肢继续使用会更容易恶化。
- 摔落保留 MC 原版生命结算，并按其最终伤害额外生成可护理的腿部伤情；右手伤情只影响挖掘，腿部伤情只影响移动。
- 服务端权威 Tick：时间、原版累计移动统计、下界、水/雨会影响状态，并同步到客户端 HUD；移动会保留连续活动负荷，短暂停下不会立刻视为完全休息。
- 生存/冒险 HUD：在饱食度上方显示水分、体温、疲劳，创造/旁观不显示。
- 身体小人 HUD：默认显示在屏幕左下角，绿色表示健康，伤势降低时逐渐转红，部位归零后变黑。
- HUD 设置页：可通过 `/eh settings` 或 Mod 列表配置入口开关身体小人，选择四个角落，调整大小和透明度；默认透明度 50%。
- 饮用恢复：水瓶、牛奶、蜂蜜瓶、蘑菇煲、兔肉煲、甜菜汤、迷之炖菜。
- 第一批身体管理物品：水壶、补液盐、电解质片、补水饮料、恢复茶、能量棒、葡萄糖凝胶、暖贴、降温包、保温毯、绷带、消毒用品、急救包、口罩和体温计。
- 绷带和急救包已接入部位治疗：绷带优先治疗最严重的非头部伤势，急救包可治疗头部。
- 白天右键床会进入短暂小睡，只恢复疲劳，不跳过白天；夜晚正常睡觉会把跳过时间折算进疲劳恢复。
- 简略锻炼系统：移动、奔跑、跳跃、挖掘、攻击和交互会训练对应部位；`/eh training` 可查看头部、躯干和四肢训练等级与当前负荷。
- 健身动作：`/eh exercise squat`、`push_up`、`core`、`stretch`、`dumbbell`、`band` 可直接测试动作。
- 健身器材：阻力带、训练垫、简易哑铃，右键会触发对应健身动作。
- 自定义肌肉拉伤效果：过度训练会触发 `earth_human:muscle_strain`，它是本 mod 的自定义状态，后续会继续扩展为部位化拉伤/恢复流程。
- 轻量后果：严重缺水、过度疲劳、过冷/过热会给出温和负面效果和预警，默认不走突然暴毙路线。
- 超凡适应联动：读取 `earth_online_arcana` 共享数据，修仙/魔法/辟谷/护体等等级可轻量影响水分消耗、疲劳、温度缓冲和额外空气时间。
- 命令入口：`/earthhuman` 和 `/eh`。
- 测试命令：`status`、`body`、`help`、`drink`、`reset`、`set hydration/fatigue/temperature/body`。
- 中英双语内置语言文件。
- 修复 26.2 配方分类兼容性，恢复茶、能量棒和葡萄糖凝胶配方可被运行时正确加载。

兼容标签与扩展说明见 [docs/compatibility.md](docs/compatibility.md)。四个独立 Mod 的职责、数据所有权、安装组合和分阶段联动计划见 [docs/earth-ecosystem-integration-roadmap.md](docs/earth-ecosystem-integration-roadmap.md)。

这是开发中测试版。当前重点是稳定加载、可测试闭环和可解释反馈；空气质量、口罩过滤和温度环境已进入第一版基础闭环，复杂医学、复杂营养和完整衣物系统仍未包含。
