# 地球：人类 / Earth Human

`地球：人类` 是一个独立 Minecraft mod，目标是复刻真实人类在世界中的身体、环境与生活约束。

它不是 `地球 Online` 的附属，也不把真实世界内容塞进同一个科技体系。两个 mod 后续通过可选联动连接：

- `地球 Online`：复刻真实世界常见物质、来源、产业、设施和路线。
- `地球：人类`：复刻真实人体、生存压力、环境影响、健康与生活系统。

当前第一版目标为 MC 26.2 / NeoForge 26.2.0.7-beta，方便先和 `地球 Online` 当前主线联动。

详细初版方案见 [docs/initial-plan.md](docs/initial-plan.md)。

## v0.1.13 测试版内容

- 新增标准 NeoForge common 配置 `earth_human-common.toml`：核心系统可独立开关，并提供轻松、标准、真实、自定义四种调节预设。
- 默认生命桥接改为 `vanilla_compatible`：保留原版和其他 Mod 的最终伤害、吸收心、治疗与死亡流程，再把吸收后真实扣血映射到身体部位。
- 可选 `head_bar` 沉浸模式继续把原版红心解释为头部，但会接管部分非头部伤害，因此兼容性低于默认模式；`overlay_only` 只显示身体状态，不施加部位惩罚。
- 修复旧身体模型在额外最大生命下迁移后比例偏低的问题；其他 Mod 改变最大生命时，已有伤势比例继续保持。
- 新增伤害类型数据标签 `bypasses_body`、`head_priority`、`full_body`，供数据包和其他 Mod 无 Java 硬依赖接入。
- 新增身体容量、旧存档迁移、兼容伤害映射、治疗溢出和规则解析自动测试。
- 快捷护理现在显示服务端真实进度，可主动取消；完成前会校验原始物品 ID 与组件，失败或无需护理时不会误耗替代物品，并在界面直接说明原因。
- 新增完整身体状态面板：概览、身体、快捷护理和显示设置四页；可用 `/eh status` 或右键野外健康记录打开。
- 快捷护理是服务端权威动作：开始后等待对应时间，完成时重新检查并消耗背包物品，不接受客户端直接修改状态。
- 护理物品兼容使用公开 item tags：其他 mod 或数据包可把物品加入补水、包扎、急救、保暖、降温分类，无需硬依赖 Java 类。
- HUD 可单独开关基础状态和身体小人，可隐藏数字、切换三种配色主题，并继续调整身体小人的角落、大小和透明度。
- `/eh status text` 保留旧文字状态输出，避免习惯旧命令或自动化调用的玩家失去入口。

- 玩家持久状态：水分、体温、疲劳。
- 部位血量第一版：头部、躯干、左臂、右臂、左腿、右腿分别记录血量。
- 原版红心保留为默认兼容入口，不再硬削最大生命；只有可选 `head_bar` 模式把红心严格同步为头部风险，其他 mod 的生命上限、治疗、护甲和复活逻辑因此有更大兼容空间。
- 其他 mod 提供的最大生命会按比例扩展全身部位容量；普通回血会先稳定头部，头部满后再扩散到躯干和四肢。
- 投掷物、爆炸和环境接触伤害的部位结算更确定：投掷物按命中/速度线估算，爆炸按爆心到身体碰撞箱最近点估算，脚下火/热地面/低位接触优先影响腿部。
- 原版 20 点基础生命被解释为头部、躯干和四肢的身体状态；身体数据首次接入时从原版血量状态生成，之后作为长期角色状态保存，不会每次复活重新分配。
- 躯干和四肢归零不会直接致死，但会带来行动/挖掘/战斗惩罚；继续使用受伤部位或再次受击时会牵连相邻部位。
- 起跳会给双腿极轻微的使用损耗；受伤腿继续跳跃会更容易恶化。
- 摔落沿用 MC 原版已经计算出的最终伤害结果，再小幅加强并映射到双腿；默认兼容模式仍保留原版生命结算。
- 服务端权威 Tick：时间、移动、奔跑、下界、水/雨会影响状态，并同步到客户端 HUD；移动会保留连续活动负荷，短暂停下不会立刻视为完全休息。
- 生存/冒险 HUD：在饱食度上方显示水分、体温、疲劳，创造/旁观不显示。
- 身体小人 HUD：默认显示在屏幕左下角，绿色表示健康，伤势降低时逐渐转红，部位归零后变黑。
- HUD 设置页：可通过 `/eh settings` 或 Mod 列表配置入口开关身体小人，选择四个角落，调整大小和透明度；默认透明度 50%。
- 饮用恢复：水瓶、牛奶、蜂蜜瓶、蘑菇煲、兔肉煲、甜菜汤、迷之炖菜。
- 第一批身体管理物品：水壶、补液盐、电解质片、补水饮料、恢复茶、能量棒、葡萄糖凝胶、暖贴、降温包、保温毯、绷带、消毒用品、急救包、口罩和体温计。
- 绷带和急救包已接入部位治疗：绷带优先治疗最严重的非头部伤势，急救包可治疗头部。
- 白天右键床会进入短暂小睡，只恢复疲劳，不跳过白天；夜晚正常睡觉会把跳过时间折算进疲劳恢复。
- 简略锻炼系统：移动、奔跑、跳跃、挖掘、攻击和交互会训练对应部位；`/eh training` 可查看部位训练等级和当前负荷。
- 健身动作：`/eh exercise squat`、`push_up`、`core`、`stretch`、`dumbbell`、`band` 可直接测试动作。
- 健身器材：阻力带、训练垫、简易哑铃，右键会触发对应健身动作。
- 自定义肌肉拉伤效果：过度训练会触发 `earth_human:muscle_strain`，它是本 mod 的自定义状态，后续会继续扩展为部位化拉伤/恢复流程。
- 轻量后果：严重缺水、过度疲劳、过冷/过热会给出温和负面效果和预警，默认不走突然暴毙路线。
- 超凡适应联动：读取 `earth_online_arcana` 共享数据，修仙/魔法/辟谷/护体等等级可轻量影响水分消耗、疲劳、温度缓冲和额外空气时间。
- 命令入口：`/earthhuman` 和 `/eh`。
- 测试命令：`status`、`body`、`help`、`drink`、`reset`、`set hydration/fatigue/temperature/body`。
- 中英双语内置语言文件。
- 修复 26.2 配方分类兼容性，恢复茶、能量棒和葡萄糖凝胶配方可被运行时正确加载。

兼容标签与扩展说明见 [docs/compatibility.md](docs/compatibility.md)。

这是开发中测试版。当前重点是稳定加载、可测试闭环和可解释反馈，暂不包含复杂医学、复杂营养、空气质量和完整衣物系统。
