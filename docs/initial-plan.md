# 地球：人类 / Earth Human 初版方案

## 1. 定位

`地球：人类` 是独立 mod，不是 `地球 Online` 的附属。

它负责复刻真实人类系统：身体状态、环境压力、健康风险、生活需求和长期生存管理。它不负责矿物、工业、材料和现代设施本身，那些属于 `地球 Online`。

一句话定位：

> 把 MC 玩家从“游戏角色”扩展成“有真实人体约束的人”，但用可配置、可理解、可关闭的方式实现。

## 2. 与地球 Online 的边界

`地球 Online` 做内容来源和现实产业：

- 矿物、岩石、土壤、水文。
- 化工、冶金、电力、机械、建材。
- 现实常见物质与处理路线。
- 保留 MC 原版便利和兼容生态。

`地球：人类` 做人体和生活压力：

- 饥饿之外的营养结构。
- 口渴、体温、疲劳、睡眠。
- 伤口、感染、中毒、疾病倾向。
- 空气质量、粉尘、烟雾、污染暴露。
- 负重、运动消耗、环境适应。
- 医疗、急救、防护装备。

联动原则：

- 两者互为可选依赖，不硬绑定。
- 没装 `地球 Online` 时，`地球：人类` 仍能独立运行。
- 装了 `地球 Online` 后，读取它的材料、化学品、防护装备、空气/污染/温度来源。
- 联动用 tags、数据包、可选 API 或事件桥接，不直接把工业路线写进人体 mod。

## 3. 不是“折磨玩家”

这个 mod 复刻真实难度，但不是为了让玩家痛苦。

设计原则：

- 默认提示清晰，不让玩家莫名其妙死亡。
- 新系统先给预警，再给轻惩罚，最后才给严重后果。
- 每个负面状态都应该有可理解的解决办法。
- 所有核心系统后续提供配置开关和强度倍率。
- 难度档位/预设先不进入第一版实现，避免拖慢核心身体系统和物品闭环。
- 默认模式适合普通玩家体验，不默认走硬核折磨。

## 4. v0.1 最小可玩闭环

v0.1 不追求完整医学模拟，先做玩家能感知、能处理、能测试的闭环。

### 4.1 人体状态数据

每个玩家保存以下基础状态：

- 水分：口渴、脱水。
- 体温：过冷、正常、过热。
- 疲劳：持续奔跑、挖掘、负重后累积。
- 睡眠债：长期不睡觉带来效率下降。
- 基础健康风险：伤口、轻微感染、中毒暴露。

状态要有三层表达：

- HUD 简要提示。
- 物品/状态 tooltip 解释。
- 手册页说明原因和解决办法。

### 4.2 可见反馈

玩家必须知道发生了什么。

- 屏幕角落显示简洁状态图标。
- 状态变差时发出短提示。
- `/earthhuman status` 查看详细状态。
- `/earthhuman help` 打开玩家帮助。
- 管理员命令可重置、调试和设置状态。

### 4.3 水分系统

第一版先做最容易理解的真实压力：

- 水分随时间、奔跑、炎热环境下降。
- 饮水恢复水分。
- 普通水、瓶装水、牛奶、汤类有不同恢复效果。
- 脏水/不安全水先不默认惩罚，留到 v0.2 或硬核配置。

解决路径：

- 直接饮用可恢复少量。
- 水瓶可靠恢复。
- 联动 `地球 Online` 时，可识别软化水、净化水、盐水等。

### 4.4 体温系统

先做低成本真实感：

- 寒冷群系、雪地、水中、夜晚提高失温风险。
- 沙漠、下界、火源附近、炎热天气提高过热风险。
- 盔甲、衣物、防护服、火焰抗性等影响热交换。
- 轻度异常先降低效率，重度异常才造成伤害。

v0.1 不做复杂湿度和风寒，只做玩家能理解的近似。

### 4.5 疲劳和睡眠

目标是让“人会累”成立，但不压死玩家：

- 长时间奔跑、跳跃、挖掘、战斗会累积疲劳。
- 睡觉、站立休息、吃合适食物可恢复。
- 疲劳影响挖掘速度、攻击速度、移动速度。
- 默认不让玩家因为疲劳直接死亡。

### 4.6 伤口和基础医疗

第一版只做轻量：

- 摔落、近战、爆炸可能产生伤口。
- 伤口会缓慢恢复；没有处理时可能恶化为感染风险。
- 绷带、消毒物、药品可降低风险。
- 先用少量新物品，不做复杂器官/骨折系统。

## 5. v0.2 方向

v0.2 开始扩展真实生存层：

- 营养结构：蛋白质、碳水、脂肪、微量元素，默认轻量化。
- 食物保存：如果用户决定放进本体，否则可拆到食品/农业联动。
- 空气质量：烟雾、粉尘、有毒气体、缺氧。
- 防护装备：口罩、防尘面具、防毒面具、防护服。
- 医疗系统：绷带、夹板、消毒、抗生素、解毒。
- 疾病系统：按风险触发，不做随机恶心玩家。

## 6. v0.3 及以后

长期方向：

- 真实负重与背包压力。
- 长期环境适应。
- 职业/体能训练。
- 真实工作安全：粉尘肺、化学灼伤、中毒、辐射等。
- 与建筑/住所/供暖/通风系统联动。
- 与 `地球 Online` 工业污染、化学品、能源设施联动。

## 7. 技术路线

首版目标：

- MC 26.2 / NeoForge 26.2.0.7-beta。
- Java 25。
- 独立 mod id：`earth_human`。
- 包名建议：`com.xxsx.earthhuman`。
- 仓库目录：`D:\_dx\_Games\MC\_agent\earth_human`。

实现面：

- 玩家持久状态数据。
- 服务端 tick 更新。
- 客户端 HUD。
- 配置文件。
- 玩家命令。
- 内置手册或帮助界面。
- 中英双语。
- 可选联动层。

## 8. 配置与档位

配置是长期必须项，但第一版先不实现档位。当前优先级是让身体状态、补给物品、HUD 和提示闭环可玩可测。

后续可考虑的预设：

- `casual`：轻量提示，低惩罚，适合普通玩家。
- `standard`：默认推荐，有明显压力但不折磨。
- `hardcore`：接近真实生存挑战。
- `pack_author`：整合包作者完全自定义。

每个系统后续都应能单独开关：

- enableThirst
- enableTemperature
- enableFatigue
- enableSleepDebt
- enableWounds
- enableInfection
- enableAirQuality
- enableNutrition

## 9. UI 原则

玩家不是来读医学论文的。

- 默认 HUD 只显示关键图标和短提示。
- 详细解释放到悬浮提示、手册和命令里。
- 状态名用玩家能懂的词：口渴、寒冷、过热、疲劳、伤口。
- 不默认显示复杂数值，除非开启高级模式。
- 出问题必须告诉玩家怎么解决。

## 10. 第一轮开发建议

第一轮不要碰完整医学，不要碰复杂营养。

建议顺序：

1. 搭建 NeoForge 26.2 独立模板。
2. 注册 mod、配置、命令、双语。
3. 实现玩家状态数据：水分、体温、疲劳。
4. 实现 HUD 和 `/earthhuman status`。
5. 做水分和体温的基础闭环。
6. 加入少量物品：水袋、简易绷带、消毒布。
7. 做 `地球 Online` 可选联动探针，但不强依赖。
8. 构建、部署、进游戏测试。

## 11. 明确暂不做

v0.1 暂不做：

- 复杂器官系统。
- 随机重病。
- 真实热力学。
- 完整食物腐败。
- 高复杂医疗。
- 心理健康模拟。
- 社会制度或 NPC 社会系统。

这些不是不能做，而是会让第一版测试效率崩掉。
