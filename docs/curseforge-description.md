# Earth Human

> **PREVIEW / TEST BUILD ONLY**
>
> Earth Human is incomplete. This build is published only for early preview,
> compatibility testing, and bug reports. Do not use it in important or long-term
> worlds without backups. Features, balance, saves, APIs, and interfaces may change
> or be removed without migration support.

Earth Human is an independent Minecraft mod that adds a realistic but approachable human body, health, activity, and environmental survival layer. It is designed to remain understandable for players who do not know technical systems while preserving compatibility with vanilla health, armor, healing, death, and other mods.

## Current Features

- Persistent hydration, body temperature, fatigue, and continuous activity load.
- A three-region condition model covering the head, torso, and limbs.
- Vanilla-compatible core combat: ordinary melee, projectiles, explosions, armor, absorption, healing, and death remain owned by Minecraft and other mods.
- Focused physical injuries: high falls can injure the legs, while bare-hand hard mining or cactus contact can injure the right hand.
- An optional separately installable Body Health add-on for players who explicitly want split body health.
- First aid, hydration supplies, temperature care, masks, and basic PPE.
- Exercise, training, muscle strain, sleeping, daytime naps, and recovery systems.
- A compact HUD and a detailed status screen with overview, body, care, and display settings.
- A beginner-friendly field health guide and built-in English and Simplified Chinese localization.
- A public compatibility API, item tags, block tags, and damage-type tags for modpacks and other mods.

## Compatibility

Earth Human can run independently. It also supports optional integration with the Earth ecosystem:

- Earth on Minecraft provides realistic materials, geology, industry, energy, and environmental sources.
- Earth Online: Magic and Earth Online: Xuanhuan can provide optional supernatural adaptation bonuses.

These integrations are optional. No sibling mod is a required dependency.

## Development Status

This project is under active development. Current files are incomplete beta previews, not finished gameplay releases. Saves, balance, compatibility APIs, and client interfaces may change between versions.

The current build has passed automated tests, resource validation, core-only and core-plus-add-on dedicated-server startup checks, and a clean client resource-load check. Manual gameplay testing remains separate from those automated checks.
